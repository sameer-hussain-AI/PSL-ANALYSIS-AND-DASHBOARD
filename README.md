# 🏏 PSL Cricket Analytics Dashboard | Power BI

**Turning Pakistan Super League ball-by-ball data into actionable cricket insights.**

An interactive Power BI analytics project designed to explore team performance, batting contributions, bowling effectiveness, and match-level trends across the Pakistan Super League (PSL). The dashboard transforms cricket data into a structured visual experience for comparing teams, evaluating players, and understanding performance beyond individual scorecards.

---

## 📌 Project Overview

Cricket generates thousands of data points throughout a tournament, from individual deliveries and player performances to team results and match outcomes. However, raw data alone does not make comparisons or performance patterns easy to understand.

This project uses **Microsoft Power BI** to organize PSL cricket data into an interactive analytical dashboard. Instead of presenting isolated statistics, it brings multiple performance dimensions together in a single reporting experience.

The dashboard is organized into dedicated analytical pages, allowing users to move from a tournament-level overview to more focused batting, bowling, and team analysis.

## 🎯 Project Objectives

- Analyze PSL performance at player and team levels.
- Present key cricket performance indicators through KPI cards and visualizations.
- Compare batting contributions and bowling performance.
- Explore team-level performance using interactive charts.
- Make cricket statistics easier to interpret through filtering and visual exploration.
- Apply Power BI data modeling, DAX measures, and dashboard design principles to a real-world sports analytics use case.

## 🧩 Data Modeling & Analytical Approach

The project uses structured cricket data to support analysis across different levels of the game.

The analytical workflow is centered on:

1. **Data preparation** — organizing source data into usable analytical tables.
2. **Data modeling** — connecting relevant datasets to support cross-table analysis.
3. **Measure development** — using DAX to calculate and present performance indicators.
4. **Dashboard construction** — separating the analysis into focused pages.
5. **Visual analysis** — using KPI cards and charts to make comparisons easier to interpret.

A key design consideration is that player-level and team-level statistics must be interpreted in the correct context. In cricket analytics, the definition of a metric and the level at which it is calculated matter just as much as the visual displaying it.

## 🎨 Dashboard Design

The report uses a dark, professional visual direction inspired by sports analytics dashboards.

Design priorities include:

- A clear visual hierarchy for important metrics
- KPI cards for quick statistical reference
- Dedicated pages to reduce analytical clutter
- Consistent layouts for easier navigation
- Charts that support comparisons rather than merely displaying numbers
- A widescreen **1920 × 1080** report layout

The intention is to balance visual appeal with analytical usability, keeping the report focused on the data.

## 🚀 How to Explore the Project

1. Clone or download this repository.
2. Locate `Cricket_Dashboard.pbix`.
3. Open the file using Microsoft Power BI Desktop.
4. Allow the report to load.
5. Navigate between Executive Overview, Batting Analysis, Bowling Analysis, Team Analysis, and DAX Measures.
6. Interact with the available report filters and visuals to explore the data.

**Requirements:** Microsoft Power BI Desktop. Data refresh may depend on the availability of the original data sources and the connection settings saved in the report.
